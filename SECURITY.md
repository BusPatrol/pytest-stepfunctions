## 📦 Security Requirements for This Repository
- Maintain an up-to-date **threat model** in Figma
- Keep **architecture diagram** current in Backstage
- **Redeploy** the application at least once per month
- Participate in **biannual security scans** and assist with remediation
- Keep the **Github Security tab** up to date
- Ensure **security-related PRs** are reviewed or assigned
- Add **security tasks to sprints** as needed
- Act as **POC for any security incidents** involving this repo
- Work with the Security Manager to review new features or PRs impacting security
## 📣 Vulnerability Disclosure Process
If you discover a potential security vulnerability in this repository or any BusPatrol system, please follow the steps below:
### 1. Report the Vulnerability
- Report to the **#eng-security** Slack channel with the following:
  - Description of the issue
  - Steps to reproduce (if possible)
  - Affected system, service, or repository
  - Your contact info (optional)
### 2. Do Not Publicly Disclose
- Please **do not share or publish** the vulnerability until our security team has reviewed and resolved it.
### 3. Response Timeline
- The security team will acknowledge your report within **3 business days**
- We'll keep you updated as we investigate and remediate the issue
### 4. Resolution
- If confirmed, we will:
  - Assign severity and track the issue internally
  - Work with engineering teams to fix it
  - Notify you when it's resolved (if you provided contact info)
### 5. Recognition
- Responsible disclosures of critical/high issues may be eligible for recognition or a small token of appreciation.
Thank you for helping us keep BusPatrol secure!
